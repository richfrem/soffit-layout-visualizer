# Soffit Layout Visualizer

An interactive Python app designed with Tkinter to visualize and calculate board courses and vent locations for your 23"-24" soffits.

## 🚀 How to Run
Open your Terminal and run the following command from this directory:

```bash
python3 app.py
```

## ⚙️ Features
1.  **Soffit Depth Slider:** Drag to match your accurate overhang depth (continuous scale 22-26").
2.  **Board Size Selectors:** Toggle between 1x4 (3.25"), 1x5 (4.25"), and 1x6 (5.25") widths.
3.  **Vent Positioning:** 
    *   **Outer Edge:** Places the 1.75" vent strip strictly on the gutter side.
    *   **1-Board Deep:** Inserts one board, then the vent strip (Matches Excel Row 1).
    *   **Center:** Approx centered placement for balanced shading symmetry.

The drawing resets immediately on action, giving you live visual feedback on the exact rip-cuts needed on your border edge!
